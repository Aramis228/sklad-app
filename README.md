# 🏪 Складская система управления

Современная веб-приложение для управления складом с красивым и удобным интерфейсом.

## ✨ Новые улучшения вкладки отчетов

### 🎨 Красивый дизайн
- **Современный градиентный дизайн** с плавными переходами
- **Анимированные карточки** с эффектами при наведении
- **Цветные бейджи** для типов оплаты (наличные/долг)
- **Интерактивные графики** с анимацией shimmer
- **Адаптивный дизайн** для всех устройств

### 📊 Улучшенная функциональность отчетов
- **Сводные карточки** с ключевыми метриками:
  - Общая выручка
  - Количество заказов
  - Проданных товаров
  - Средний чек
- **Детализированная таблица продаж** с информацией о клиентах
- **Интерактивный график** топ-продаж товаров
- **Фильтры по периодам**: сегодня, вчера, неделя, месяц, все время

### 🎯 Особенности дизайна

#### Цветовая схема
- **Основные цвета**: синий градиент (#3b82f6 → #1d4ed8)
- **Акценты**: фиолетовый (#8b5cf6), голубой (#06b6d4)
- **Успех**: зеленый (#10b981)
- **Предупреждение**: оранжевый (#f59e0b)

#### Анимации и эффекты
- **Hover эффекты** на всех интерактивных элементах
- **Плавные переходы** (0.3s ease)
- **Shimmer анимация** на графиках
- **Scale эффекты** при наведении
- **Тени и градиенты** для глубины

#### Типографика
- **Современный шрифт**: Inter
- **Четкая иерархия** заголовков
- **Uppercase** для лейблов и бейджей
- **Letter-spacing** для лучшей читаемости

### 📱 Адаптивность
- **Мобильная версия** с оптимизированным интерфейсом
- **Гибкая сетка** для разных размеров экрана
- **Уменьшенные элементы** на маленьких экранах
- **Вертикальное расположение** кнопок на мобильных

### 🔧 Технические улучшения
- **Оптимизированный CSS** с современными свойствами
- **Улучшенный JavaScript** с лучшей обработкой данных
- **Семантическая HTML структура**
- **Доступность** (accessibility) элементов

## 🚀 Как использовать

1. Откройте `index.html` в браузере
2. Перейдите на вкладку "Отчеты" в боковой панели
3. Выберите период и дату для анализа
4. Нажмите "Сгенерировать отчет"
5. Просматривайте красивые графики и статистику

## 📈 Возможности системы

- **Управление товарами** с категориями
- **Ведение клиентской базы**
- **Создание накладных** с различными типами оплаты
- **Контроль долгов** клиентов
- **Отслеживание движения** товаров
- **Детальная аналитика** продаж

